# LYRIS-BIBEL · App

Eigenständige deutsche Übersetzung der Bibel aus den Grundsprachen. Vorläufige Teilausgabe als Web-App:
https://bibel.lyris.ch/

Dieses Repository enthält nur die erzeugte App; jede neue Fassung ersetzt die vorige. Übersetzung, Fussnoten,
Einleitungen und Verzeichnisse sind mit einem Sprachmodell (Claude, Anthropic) nach der Konzeption der
LYRIS-BIBEL erarbeitet; LYRIS arbeitet sämtliche Texte von Hand durch.

Die LYRIS-BIBEL soll grundsätzlich frei zugänglich sein; eine Lizenz wird geprüft. Grundtexte und Rechte:
im Anhang der App. Kontakt: info@lyris.ch
